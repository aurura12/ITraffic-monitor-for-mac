# VPN / Proxy Attribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve delayed proxy attribution without assigning old traffic to the wrong app, and prevent TCP/UDP source-port collisions.

**Architecture:** Proxy API deltas become timestamped pending credits. A visible proxy `nettop` row consumes the oldest eligible credits up to its direction-specific observed bytes; credits expire after ten seconds. Socket owner maps and controller connections use a `SocketKey` composed of transport protocol and source port.

**Tech Stack:** Swift 5, Foundation, AppKit, XCTest, macOS 14+

## Global Constraints

- Preserve the existing Clash, Clash Verge, and Surge controller integrations.
- Never transfer a credit without a visible proxy `nettop` row.
- Drop stale credits after exactly 10 seconds and log the drop.
- Do not use a port-only PID lookup when the controller omits transport protocol.
