# 每小时阶梯流量图与首页实时网速设计

## 目标

修复首页今日流量图将不同小时的增量斜线连接、造成视觉上“回到原点”的问题，同时在首页顶部统计卡片区域展示实时下载和上传速度。

## 现状与根因

历史查询返回的是每个时间桶内的流量增量。今日视图将每小时增量作为一个点，并使用普通折线连接相邻点，因此一个小时的值会被斜线过渡到下一个小时的值，无法表达“该值属于整个小时”的语义。

## 方案

### 小时流量图

- 保留数据库和 ViewModel 的增量数据口径，不转换为累计值。
- 为今日视图生成显式的小时边界阶梯点：每小时区间内保持该小时增量，在整点切换到下一小时值。
- 使用 Swift Charts 的阶梯插值绘制下载和上传两条线，避免跨小时的斜线过渡。
- 悬浮提示仍展示所选小时的下载、上传和总量增量。
- 7 天和 30 天视图继续使用日增量；它们也采用阶梯插值，保持时间桶语义一致。

### 实时网速

- 复用已有的 `RealtimeRateStore`，不新增采集链路或数据库字段。
- 首页顶部增加实时下载和上传卡片，订阅最近样本并以 bytes/s 格式展示。
- 没有样本时显示 `0 KB/s`。
- 实时卡片只反映当前速率，不影响历史统计卡片。

## 测试与验证

- 测试小时增量转换为阶梯点时，每个小时值被保持到下一个边界。
- 测试缺失小时仍补零且保持 24 小时范围。
- 测试实时速率格式化和空样本状态。
- 运行项目单元测试，并执行 Debug 构建验证 Swift Charts API 与 macOS 14 部署目标兼容。
